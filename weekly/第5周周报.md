## 遇到的问题与解决情况
1. 动态链接缓存未刷新 → sudo ldconfig（已解决）；
2. mavsdk 4.x API 换代与项目代码不兼容 → 降级 mavsdk<4（已解决）；
3. mavsdk 3.x 与 Gazebo 绑定 protobuf 版本互斥 → 同代降级 mavsdk 2.8.4 + protobuf 3.20.3 + .pth 挂载（已解决）；
4. mavsdk 2.8.4 导入时自动启用 uvloop 与 aiogrpc 不兼容 → 卸载 uvloop（已解决）；
5. 起飞链路（未解决，已定位根因）：mavsdk 2.8.4（唯一与 Gazebo 绑定兼容的版本）在 PX4 1.15.4 下出现 MAVLink 命令确认竞态（"Received ack for not-existing command"），mavsdk_server 崩溃；兼容 PX4 1.15 的 mavsdk 3.17.4 又与 Gazebo 绑定 protobuf 约束互斥（≤3.20 vs ≥6.32）。
